# Red Stone of Aja (Forge 1.20.1)
Fuegt den Roten Stein von Aja hinzu. Steinmaske (JCraft: Eyes of Ender) tragen und mit dem Stein
rechtsklicken: der Spieler ist dauerhaft vor Sonnenlicht geschuetzt (Stein wird verbraucht, Schutz bleibt nach dem Tod).
Gebaut wird die Jar von GitHub Actions (Reiter "Actions" -> Lauf -> Artifacts).
